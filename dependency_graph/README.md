# NCT blueprint dependency graph

This directory contains a two-stage Python pipeline:

```text
LaTeX blueprint -> graph.json -> standalone interactive HTML
```

The renderer consumes only `graph.json`. It never reads the source `.tex` file.

## Files

- `latex_to_graph_json.py` — extracts headings, theorem/definition nodes, `\using` dependencies, visibility, expanded statements, and compiled reference numbers.
- `graph_json_to_html.py` — computes six independent Graphviz layouts and writes a self-contained interactive HTML file.
- `graph.json` — generated graph data for the supplied manuscript.
- `graph.schema.json` — JSON Schema Draft 2020-12 definition of format version 2.0.0.
- `GRAPH_FORMAT.md` — semantic format specification.
- `nct_dependency_graph.html` — standalone interactive graph.
- `nct_dependency_graph.svg` — static default-layout SVG.
- `nct_dependency_graph.dot` — fixed-position Graphviz source for the default layout.
- `layout_metadata.json` — node and cluster geometry for all six layouts.
- `nct_dependency_graph_overview.png` — static preview.
- `UPSTREAM_NOTES.md` — relation to the Lean Carleson/Lean blueprint graph conventions.
- `SHA256SUMS` — checksums of delivered artifacts.

## Requirements

- Python 3.10 or later
- `latexmk` and the LaTeX packages required by the manuscript
- Graphviz executables `dot` and `neato`
- a local MathJax `tex-svg-full.js` bundle
- `jsonschema` only for the optional schema-validation command below

The renderer searches two common global MathJax locations. Supply another location explicitly with `--mathjax-js`.

## Rebuild the JSON

```bash
python3 latex_to_graph_json.py \
  '/path/to/260809-pass-4-nct-blueprint-generated-edited(3).tex' \
  graph.json \
  --strict
```

By default, the extractor runs `latexmk` in a temporary directory and reads the resulting `.aux` file so that statement references retain the numbers generated by LaTeX. An existing auxiliary file may be used instead:

```bash
python3 latex_to_graph_json.py blueprint.tex graph.json \
  --aux-file blueprint.aux \
  --strict
```

Useful extractor options:

```text
--granularity {none,section,subsection}
--[no-]include-definitions
--status STATUS_ID
--aux-file FILE
--latexmk-binary EXECUTABLE
--strict
```

## Render the graph

```bash
python3 graph_json_to_html.py graph.json nct_dependency_graph.html \
  --svg-output nct_dependency_graph.svg \
  --dot-output nct_dependency_graph.dot \
  --layout-metadata-output layout_metadata.json
```

When MathJax is not installed in one of the renderer’s default locations:

```bash
python3 graph_json_to_html.py graph.json nct_dependency_graph.html \
  --mathjax-js /path/to/mathjax-full/es5/tex-svg-full.js
```

The generated HTML embeds the graph data, six SVG layouts, application JavaScript, styles, and MathJax. It can be opened directly without the LaTeX source or a network connection.

## Interactive controls

The Settings button opens a temporary settings panel. Controls include:

- hierarchy visibility: `None`, `Section`, or `Subsection`;
- include or exclude definitions;
- public, private, section, and subsection opacity;
- show or hide the whole sidebar;
- show or hide the legend independently;
- show or hide the document hierarchy independently;
- export the currently visible graph viewport as SVG or PNG.

The default private-node opacity is 50 percent. Opacity applies to the entire node group.

Search filters while typing. During a nonempty search, only matching nodes remain visible; edges and hierarchy boxes are hidden. Search covers labels, titles, expanded statements, and Lean names.

Clicking a section or subsection caption toggles a box filter. Nodes outside that box and every incident edge are hidden. Clicking the same caption again restores them.

Clicking a node opens its metadata, MathJax-rendered statement, dependencies, reverse dependencies, and expanded LaTeX. Numbered references to graph nodes are links. The copy-icon button beside Expanded LaTeX copies the source to the clipboard.

## Layout rules

The renderer computes separate coordinates for all combinations:

```text
none       × theorem-only / theorem-plus-definition
section    × theorem-only / theorem-plus-definition
subsection × theorem-only / theorem-plus-definition
```

In section and subsection modes, the Introduction is placed above every other section. In subsection mode, subsection cells partition the usable section interior, except for fixed margins and gutters. The synthetic cell for material directly under a section has no visible caption.

## Validate the data

```bash
python3 - <<'PY'
import json
from pathlib import Path
from jsonschema import Draft202012Validator, FormatChecker

schema = json.loads(Path('graph.schema.json').read_text())
graph = json.loads(Path('graph.json').read_text())
Draft202012Validator.check_schema(schema)
Draft202012Validator(schema, format_checker=FormatChecker()).validate(graph)
print('valid')
PY
```

Strict extraction additionally checks dependency resolution, acyclicity, reference numbering, and custom-macro expansion.
